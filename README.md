# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to understand sales performance, product trends, customer purchasing patterns, and regional sales insights.

The project includes raw data, cleaned data, analysis, and an interactive Excel dashboard for data visualization.

## 🛠️ Tools Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas
* PivotTables
* PivotCharts
* Slicers
* Dashboard Visualization

## 📌 Key Analysis

* Overall Sales Performance
* Product-wise Sales Analysis
* Sales Trend Analysis
* Regional Sales Analysis
* Customer and Order Analysis
* Key Sales Metrics

## 📁 Project Files

* **Raw Data** – Original e-commerce sales dataset
* **Clean Data** – Prepared and cleaned dataset
* **Dashboard** – Interactive Excel dashboard

## 🎯 Objective

The objective of this project is to analyze e-commerce sales data and create an interactive Excel dashboard that presents sales trends, product performance, regional insights, and key business metrics.
